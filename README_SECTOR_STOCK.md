## 📊 策略核心逻辑

### 板块筛选条件
1. 过去60天内有过爆发（单日>3%）
2. 爆发后回撤5-15%（洗盘）
3. 近15日表现弱(<5%)但近5日企稳(>-5%)

### 个股筛选条件
1. 过去60天内有过大涨（单日>5%或3日>10%）
2. 之后回撤8-20%
3. 近10日横盘（振幅<12%）
4. 当前价格接近横盘区间下沿（<5%）

### 市场情绪评分（7分制）

| 指标 | 评分规则 |
|------|----------|
| 波动率 | ≥1.5%: 3分<br>≥1.0%: 2分<br>≥0.8%: 1分 |
| 趋势 | 收盘>MA5>MA20: 2分<br>收盘>MA20: 1分 |
| 涨天数 | 近5日≥4天: 2分<br>近5日≥3天: 1分 |
| 涨幅 | 10日>2%: 1分 |

**操作门槛：** 评分≥4分才建议操作

## 🎮 实战操作流程

### Step 1: 每日检查市场情绪

```bash
python sector_stock_strategy.py --scan
```

如果提示"不适合操作"，则：
- 不要操作
- 继续观察
- 等待情绪改善

### Step 2: 情绪改善时扫描

当市场情绪评分≥4时：
- 策略会自动扫描
- 导出Excel结果
- 查看潜力个股

### Step 3: 人工复核

**必须检查：**
1. 板块是否有逻辑支撑（政策、事件、资金）
2. 个股基本面是否正常（不能有重大利空）
3. 技术形态是否符合预期（K线、成交量）
4. 当前价格是否在合理位置（不追高）

### Step 4: 分批建仓

**建议：**
- 首次建仓：30%仓位
- 回调加仓：再加30%
- 突破加仓：再加40%
- 单只上限：10%

### Step 5: 持仓管理

**止损：**
- 跌破买入价-8%，止损离场
- 或跌破10日均线，止损离场

**止盈：**
- 盈利>15%，减仓50%
- 盈利>25%，减仓至30%
- 回撤>5%，全部离场

**持有周期：**
- 目标：60天
- 最短：30天（除非触发止损）
- 最长：90天（超过则考虑离场）

## ⚠️ 重要提示

### 必须遵守的规则

1. **严格遵守市场情绪过滤**
   - 评分<4不操作
   - 不要自作聪明强行操作

2. **设置止损**
   - 不要死扛
   - 亏损8%必须离场

3. **控制仓位**
   - 单只≤10%
   - 总仓位≤30%

4. **中长线持有**
   - 不要短炒
   - 给策略时间发挥

### 不适合这个策略的情况

❌ 短线交易者
❌ 追求高频操作
❌ 无法承受10%回撤
❌ 市场情绪长期低迷

### 适合这个策略的情况

✓ 中长线投资者
✓ 能承受短期波动
✓ 有耐心等待信号
✓ 严格执行纪律

## 📞 问题排查

### Q1: 扫描很慢怎么办？

**原因：** 需要获取大量股票数据

**解决：**
- 减少扫描板块数量（修改代码中的100改为50）
- 增加线程数（修改max_workers=10）
- 使用强制扫描版本（已优化）

### Q2: 长时间没有信号？

**原因：** 市场情绪不佳或没有符合条件的板块

**解决：**
- 这是正常的，策略本身信号频率就低
- 可以用强制扫描版本研究潜力板块
- 耐心等待市场情绪改善

### Q3: 回测结果不理想？

**原因：** 样本量小（仅8个信号）

**解决：**
- 扩大回测时间范围（修改start_date）
- 降低筛选标准，增加信号数量
- 结合其他策略使用

### Q4: 如何判断市场情绪何时改善？

**观察指标：**
1. 5日波动率>1.0%
2. 大盘站上5日均线
3. 连续3天收阳
4. 成交量放大

**快速检查：**
```bash
python sector_stock_strategy.py --scan
```
