🎯 策略核心
--------------------------------------------------------------------------------
在年报发布前1-3天，捕捉季报扭亏+横盘整理+大单上打的股票

📊 信号体系 (总分100分)
--------------------------------------------------------------------------------
✓ 季报扭亏 (30分) - 基本面改善的先行指标
✓ 横盘整理 (25分) - 波动率<5%，主力控盘
✓ 大单上打 (25分) - 主力间歇性试盘/拉升
✓ 主力控盘 (20分) - 低换手率<3% 或 低振幅<5%

⚠️ 重要提示
================================================================================

1. 数据获取
   如果API获取失败，使用手动模式：
   
   manual_list = [
       ('600000', '浦发银行', '2025-03-28'),
       ('000001', '平安银行', '2025-03-25'),
   ]

2. 回测验证
   至少回测10只以上股票才有统计意义

3. 风险控制
   - 设置止损: 跌破横盘区间
   - 分批建仓: 年报前分批买入
   - 及时止盈: 短期暴涨及时获利

4. 策略优化
   根据回测结果调整参数和阈值
