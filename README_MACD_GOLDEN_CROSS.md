# MACD金叉策略 - 使用指南

## 📊 策略原理

### MACD指标说明

**MACD (Moving Average Convergence Divergence)** - 指数平滑异同移动平均线

**三条线：**
1. **MACD线（DIF）**：快线EMA(12) - 慢线EMA(26)
2. **Signal线（DEA）**：MACD的9日EMA
3. **Histogram（柱状图）**：MACD - Signal

### 金叉信号

**定义：** MACD线从下方上穿Signal线

**分类：**
1. **0轴上方金叉** - 强势上涨信号（推荐）
   - MACD和Signal都在0轴上方
   - 表示多头趋势中的加速上涨
   - 胜率较高，适合追涨

2. **0轴下方金叉** - 底部反转信号
   - MACD和Signal都在0轴下方
   - 表示空头趋势可能反转
   - 风险较高，需要确认

### 信号强度判断

**强信号特征：**
- ✓ MACD值较大（>0.5）
- ✓ 金叉角度陡峭（cross_strength大）
- ✓ 柱状图为正（红柱）
- ✓ MACD向上趋势明显

**弱信号特征：**
- ✗ MACD值接近0
- ✗ 金叉角度平缓
- ✗ 柱状图为负（绿柱）
- ✗ MACD横盘


- 信号数量多
- 适合选股

**输出：**

- 统计分析


**特点：**
- 只扫描0轴上方金叉
- 信号质量高

### 3. 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| --mode | 扫描模式（strict/loose） | loose |
| --workers | 线程数 | 10 |

## 📈 信号解读

### 输出字段说明

| 字段 | 说明 | 参考值 |
|------|------|--------|
| MACD | MACD线值 | >0.5为强 |
| Signal | Signal线值 | - |
| Histogram | 柱状图值 | >0为红柱 |
| cross_strength | 金叉强度 | 越大越好 |
| macd_trend | MACD趋势 | >0向上 |
| position | 位置 | 0轴上方/下方 |
| potential_gain | 潜在收益 | 到近期高点的空间 |

### 示例输出

```
[110/3057] ✓ 601100 恒立液压 MACD:3.4737 0轴上方
[128/3057] ✓ 001285 瑞立科密 MACD:2.1362 0轴上方
[33/3057] ✓ 603163 圣晖集成 MACD:5.9015 0轴上方
```

**解读：**
- 圣晖集成：MACD=5.9015，非常强的金叉信号
- 恒立液压：MACD=3.4737，强金叉信号
- 瑞立科密：MACD=2.1362，中等强度金叉

## 🎮 实战操作

### Step 1: 扫描市场

```bash
python scan_macd_golden_cross.py --mode loose
```

等待扫描完成（约5-10分钟）

### Step 2: 查看结果

**Excel文件包含3个Sheet：**
1. **0轴上方金叉** - 强势股列表
2. **0轴下方金叉** - 底部反转股列表
3. **统计分析** - 整体数据

### Step 3: 筛选个股

**优先选择：**
1. MACD值 > 1.0
2. 0轴上方金叉
3. 今日涨幅 < 5%（避免追高）
4. 潜在收益 > 10%

**排除：**
1. MACD值 < 0.1（信号太弱）
2. 今日涨幅 > 7%（已经涨太多）
3. 换手率 < 1%（流动性差）

### Step 4: 人工复核

**必须检查：**
1. K线形态是否健康
2. 成交量是否放大
3. 是否有重大利空
4. 行业和板块是否有逻辑

### Step 5: 建仓策略

**分批建仓：**
- 金叉当日：建仓30%
- 回调不破Signal线：加仓30%
- 突破前高：加仓40%

**仓位控制：**
- 单只：≤10%
- 总仓位：≤50%

### Step 6: 持仓管理

**止损：**
- MACD死叉（跌破Signal线）：立即止损
- 跌破买入价-5%：止损
- 跌破10日均线：止损

**止盈：**
- 盈利>15%：减仓50%
- 盈利>30%：减仓至30%
- MACD死叉：全部离场

**持有周期：**
- 短线：5-10天
- 中线：20-30天
- 长线：持有到死叉

## 📊 策略优势

### ✅ 优点

1. **客观量化** - 基于数学计算，无主观判断
2. **趋势跟踪** - 能捕捉趋势启动点
3. **信号明确** - 金叉/死叉清晰可见
4. **适用性广** - 适合各种市场环境

### ⚠️ 缺点

1. **滞后性** - 金叉出现时可能已经涨了一段
2. **震荡市失效** - 横盘时会频繁金叉死叉
3. **假信号** - 0轴下方金叉可能是假突破
4. **需要确认** - 单纯金叉不够，需要结合其他指标

## ⚠️ 风险提示

### 高风险情况

1. **震荡市** - 频繁金叉死叉，容易被打脸
2. **0轴下方金叉** - 可能是反弹，不是反转
3. **MACD值太小** - 信号太弱，可能无效
4. **追高** - 金叉当日已经涨停，不要追

### 风险控制

1. **严格止损** - 死叉必须离场
2. **控制仓位** - 单只不超过10%
3. **分散投资** - 不要重仓单只
4. **结合其他指标** - 不要只看MACD

## 📝 常见问题

### Q1: 金叉后立即买入还是等回调？

**建议：**
- 强金叉（MACD>1.0）：可以立即买入
- 弱金叉（MACD<0.5）：等回调到Signal线再买
- 0轴下方金叉：等上穿0轴再买

### Q2: 金叉后涨了很多还能买吗？

**建议：**
- 涨幅<3%：可以买
- 涨幅3-5%：谨慎买
- 涨幅>5%：不建议追高

### Q3: 金叉后多久会死叉？

**统计：**
- 强趋势：20-30天
- 弱趋势：5-10天
- 震荡市：2-3天

**建议：** 不要预测，死叉就离场

### Q4: 0轴下方金叉能买吗？

**建议：**
- 谨慎对待
- 等待更多确认（如上穿0轴）
- 或等待第二次金叉
- 仓位要小

### Q5: 如何判断金叉的可靠性？

**可靠金叉特征：**
1. MACD值 > 0.5
2. 0轴上方金叉
3. 成交量放大
4. 股价在均线上方
5. 板块有逻辑支撑

**不可靠金叉特征：**
1. MACD值 < 0.1
2. 0轴下方金叉
3. 成交量萎缩
4. 股价在均线下方
5. 板块无逻辑
