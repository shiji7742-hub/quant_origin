# 年报扭亏策略

## 策略逻辑

这是一个基于业绩预期和主力行为的组合策略，核心思想是：**在年报发布前捕捉可能扭亏的股票**。

### 核心信号

1. **季报扭亏** (30分)
   - 上一季度亏损，最新季度盈利
   - 说明：基本面改善的先行指标

2. **横盘整理** (25分)
   - 近10日波动率 < 5%
   - 说明：价格稳定，主力控盘吸筹

3. **大单上打** (25分)
   - 大单成交占比 > 20%
   - 向上大单占比 > 60%
   - 说明：主力间歇性试盘/拉升

4. **主力控盘** (20分)
   - 低换手率 < 3% 或 低振幅 < 5%
   - 说明：筹码集中，主力高度控盘

### 时间窗口

- 年报发布前 1-3 天
- 这是信息不对称的最佳时机

## 评分标准

- **80-100分**: ⭐⭐⭐ 强烈推荐 - 四个信号全部满足
- **60-79分**: ⭐⭐ 值得关注 - 三个核心信号满足
- **40-59分**: ⭐ 观察 - 两个信号满足
- **<40分**: 不符合条件

## 风险提示

1. **业绩不确定性**: 季报扭亏不代表年报一定扭亏
2. **信息滞后**: 年报数据可能已被提前泄露
3. **主力诱多**: 横盘+大单可能是出货手法
4. **市场环境**: 大盘下跌时个股难以独善其身

## 操作建议

1. **提前布局**: 年报前2-3天介入
2. **分批建仓**: 不要一次性满仓
3. **设置止损**: 跌破横盘区间止损
4. **及时止盈**: 年报发布后根据实际情况决定
5. **结合其他指标**: 配合MACD、成交量等技术指标

## 历史回测

### 回测工具

我们提供了3个回测工具：

#### 1. 完整回测 (backtest_annual_turnaround.py)

自动回测最近已披露年报的扭亏股票：

```bash
python backtest_annual_turnaround.py
```

功能：
- 自动获取最近60天已披露年报的股票
- 检查是否年报扭亏
- 分析年报前一天的信号
- 计算年报后1/3/5/10日收益
- 统计信号有效性

#### 2. 查找扭亏股票 (find_turnaround_stocks.py)

帮助你找到扭亏股票用于回测：

```bash
python find_turnaround_stocks.py
```

功能：
- 全市场扫描2024年扭亏股票
- 获取年报披露时间表
- 快速检查指定股票是否扭亏

#### 3. 快速回测 (quick_backtest_turnaround.py)

针对单只股票的详细回测：

```python
from quick_backtest_turnaround import quick_backtest

# 回测单只股票
quick_backtest('600000', '浦发银行', '2025-03-28')
```

输出：
- 年报扭亏确认
- 年报前信号评分
- 年报后各期收益
- 策略有效性评估

### 回测流程

```
1. 使用 find_turnaround_stocks.py 找到扭亏股票
   ↓
2. 记录股票代码、名称、披露日期
   ↓
3. 使用 quick_backtest_turnaround.py 详细回测
   或
   使用 backtest_annual_turnaround.py 批量回测
   ↓
4. 分析结果，验证策略有效性
```

### 回测指标

- **信号评分**: 0-100分，评估年报前信号强度
  - 横盘整理: 40分
  - 低振幅: 30分
  - 低换手: 30分

- **收益率**: 年报披露日开盘买入后的收益
  - 1日收益: 次日表现
  - 5日收益: 短期表现
  - 10日收益: 中期表现

- **有效性**: 信号评分 vs 实际收益的相关性
