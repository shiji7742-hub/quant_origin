# 🤖 AI自主交易系统

> 一个会自己学习交易的AI系统

## 这是什么？

这不是一个需要你操作的交易工具，而是一个**会自己做交易、自己复盘、自己学习优化的AI系统**。

你只需要启动它，然后AI会：
- 🔍 自己扫描市场找机会
- 💰 自己决定买什么、卖什么
- 📊 自己管理仓位和风险
- 📈 自己分析交易表现
- 🧠 自己总结经验教训
- 🎯 自己优化交易策略

## 快速开始（3步）

### 1️⃣ 安装依赖
```bash
pip install -r requirements.txt
```

### 2️⃣ 测试系统
```bash
python test_ai_trading.py
```

### 3️⃣ 开始运行
```bash
# Windows用户
run_ai_trading.bat

# 或直接运行
python auto_trading_system.py
```

**就这么简单！** AI会自动完成所有工作。

## 核心特性

### ✅ 完全自动化
- 自动选股（11分评分系统）
- 自动交易（买入/卖出）
- 自动风控（止盈/止损）
- 自动复盘（分析/学习）

### ✅ 智能学习
- 记录每笔交易的原因和结果
- 分析盈利和亏损的模式
- 发现有效和无效的信号
- 生成优化建议

### ✅ 风险控制
- 止损：-8%
- 止盈：+20%
- 时间止盈：15天
- 最多持仓：5只
- 单只仓位：15%

### ✅ 数据完整
- 所有交易记录
- 每日账户快照
- 学习日志
- Excel报告

## 系统架构

```
virtual_portfolio.py    # 虚拟账户（资金、持仓、交易）
    ↓
ai_trader.py           # AI交易员（选股、决策、执行）
    ↓
ai_review.py           # AI复盘师（分析、学习、优化）
    ↓
auto_trading_system.py # 完整流程（每日自动运行）
```

## 使用场景

### 场景1：完全托管（推荐）
```bash
python schedule_trading.py
```
每天15:30自动运行，你什么都不用管。

### 场景2：手动触发
```bash
python auto_trading_system.py
```
每天手动运行一次，掌控运行时间。

### 场景3：只看不动
```bash
python view_portfolio.py
python ai_review.py
```
只查看AI的表现，不执行交易。

## 常见问题

**Q: 这是真实交易吗？**
A: 不是，这是模拟交易，使用虚拟资金（默认10万）。

**Q: AI真的会学习吗？**
A: 是的！AI会记录所有交易，分析成功失败，总结经验，生成优化建议。

**Q: 可以用于实盘吗？**
A: 建议先模拟测试，充分验证后再考虑实盘。

**Q: 如何调整策略？**
A: 编辑 `ai_trader.py` 中的参数（止盈止损、仓位等）。

**Q: 数据保存在哪？**
A: `virtual_trading_data/` 目录下的JSON文件。

## 重要提示

⚠️ **这是学习工具，不是投资建议**
- 使用虚拟资金，不涉及真实交易
- 历史表现不代表未来收益
- 市场有风险，投资需谨慎
- 实盘前请充分测试
